# columns

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one or more rows of columns; media-text: image column + text column (heading, paragraph, optional list, CTA); cta-strip: text column + button column; images: image-only columns.

## Supported variations

| Variation | Option class |
| --- | --- |
| Media Text | `media-text` |
| Cta Strip | `cta-strip` |
| Images | `images` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Media Text, Cta Strip, Images.
