# hero

Custom **hero** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image cell (background) + text cell (heading, optional subheading/paragraph, 1-3 CTAs); promo-panel places the text in a panel over a full-bleed image.

## Supported variations

| Variation | Option class |
| --- | --- |
| Promo Panel | `promo-panel` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Promo Panel.
